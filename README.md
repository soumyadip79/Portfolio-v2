## 📌 Project Overview

**Soumyadip.dev** is a personal developer portfolio engineered to present projects, algorithmic skills, and technical expertise in a clean, visual-first format. Designed with a dark cyber-aesthetic, the site uses custom CSS animations and glowing neon borders to highlight key interactive components, while maintaining fast load times and responsive cross-device compatibility.

---

## ✨ Key Features & Highlights

* 🌌 **Dark Neon Aesthetic:** Styled with a deep black backdrop (`#000000`) paired with cyan (`#00EEFF`) glowing accents to create a high-contrast theme.
* ✍️ **Dynamic Typing Animation:** Integrates real-time JavaScript text transitions to cycle through engineering specializations (Competitive Programming, Full-Stack Development).
* 📸 **Interactive Avatar Frame:** Features a glowing circular profile frame built using CSS `box-shadow` layering and smooth hover transitions.
* 🔗 **Integrated Social Hub:** Quick-access glowing icon buttons for direct connections via LinkedIn, GitHub, Email, and WhatsApp.
* 📄 **Action-Oriented CTA:** Dedicated resume download trigger designed for quick recruiter access.
* 📱 **Mobile-First Responsiveness:** Seamless layout adjustments across smartphones, tablets, laptops, and ultra-wide displays.

---

## 📱 Responsive Design & Adaptation

The website employs a mobile-responsive layout built with modern CSS techniques to guarantee an optimal user experience across all viewports.

### 📐 Breakpoint Architecture

| Device Category | Viewport Width | Layout Strategy |
| :--- | :--- | :--- |
| **Mobile Devices** | `< 768px` | Single-column fluid layout, stacked hero elements, scaled font sizes, and touch-optimized interactive elements |
| **Tablets & iPads** | `768px - 1024px` | Flexible two-column grid adjustments, auto-scaling avatar frame, and responsive padding |
| **Desktops & Wide Displays** | `> 1024px` | Full side-by-side hero layout, expanded hover states, and maximum glow depth effects |

### ⚡ Responsive Highlights
* **Fluid Typography:** Utilizes CSS `clamp()` and relative units (`rem`, `vw`) to keep titles and hero text readable across screen sizes without awkward wrapping.
* **Adaptive Flex Layouts:** Uses CSS Flexbox with column re-ordering so media elements stack cleanly above or below text content on smaller screens.
* **Touch-Optimized Controls:** Button targets and social icons maintain minimum touch-target padding (44px+) for comfortable mobile browsing.
* **Viewport Optimization:** Configured with a viewport meta tag for accurate pixel rendering on high-DPI (Retina) mobile screens.
